# Coding Club Website

Trang web gioi thieu Coding Club cua sinh vien VNU-IS. Site gom nam trang tinh,
viet bang HTML va CSS thuan, khong dung framework. Muc dich la gioi thieu hoat
dong cua cau lac bo va cho phep sinh vien moi tim cach lien he.

## Pages
- Home (index.html)
- About (about.html)
- Activities (activities.html)
- Media (media.html)
- Contact (contact.html)

## Technologies
- HTML5
- CSS3
- Google Fonts (Poppins, Open Sans)

## How to Run
Tai ca thu muc project ve may, sau do mo file `index.html` bang bat ky trinh duyet
nao. Khong can cai them gi va khong can may chu.
