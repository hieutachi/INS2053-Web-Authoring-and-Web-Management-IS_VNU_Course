# Homework 1: My First Personal Page

## Due Date
Sunday, 23:59 (Week 2)

## Objective
- Practice basic HTML document structure
- Learn to use common HTML tags
- Create your first web page from scratch

## Requirements

### Task 1: Create Your Personal HTML Page
Build a simple HTML page that introduces yourself to the class.

**Your page must include:**
- A proper HTML5 document structure (DOCTYPE, html, head, body tags)
- A title in the `<head>` section (your name)
- A main heading (`<h1>`) with your name
- A paragraph describing who you are (2-3 sentences about yourself)
- A paragraph about your hobby or favorite activity
- At least one image (can be a placeholder from the internet)
- A link to your favorite website

**File path:** Create the file at:
```
homework/session-01/index.html
```

### Task 2: Add Basic Formatting
Enhance your page with simple formatting:
- Add a horizontal line (`<hr>`) between sections
- Use line breaks (`<br>`) where appropriate
- Make your name bold using `<strong>` tags

**Requirements checklist:**
- [ ] Valid HTML5 document
- [ ] At least 2 paragraphs
- [ ] At least 1 image with alt text
- [ ] At least 1 link
- [ ] Proper heading hierarchy

## Submission Guide
- Save your file in the correct location
- Add your work to Git: `git add homework/session-01/index.html`
- Commit with message: `git commit -m "HW1: Add personal page"`
- Push to your GitHub repository: `git push`
