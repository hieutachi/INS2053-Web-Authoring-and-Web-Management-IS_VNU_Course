Multi-Page Architecture

Slide 5 of 30 #

One Template, Many Pages

Header, nav, sidebar, and footer stay the same on every page.

Only the <main> content changes per page.

All pages link to the same css/style.css file.

i
Workflow: build index.html completely, then Save As for each new page. Change the title, move the active class, replace main content.
6

Copy-and-Modify Checklist

Slide 6 of 30 #

The 5-Step Page Creation Checklist

Step 1 — File > Save As > new-page.html (same folder).

Step 2 — Change <title> to "Student Club - Page Name".

Step 3 — Move class="active" to THIS page's nav link.

Step 4 — Replace ONLY the <main> content.

Step 5 — Verify header, nav, aside, footer are identical.

×
Common mistake: Forgetting Step 3! The wrong page stays highlighted in the nav. Always check the active class.

Relative Links

Slide 7 of 30 #

Relative Links Between Pages

×
Never use absolute paths like C:\Users\... — they only work on YOUR computer. Always use forward slashes (/).
8

Path Reference Table

Slide 8 of 30 #

Relative Path Quick Reference

Same Folder

<a href="about.html">About</a>

Just the filename. No path prefix needed.

Into a Subfolder

html
1<link href="css/style.css">2<img src="images/logo.png">

folder/filename — goes DOWN into a folder.

Up to Parent Folder

<a href="../index.html">Home</a>

../ means "go up one level". Used from pages/ subfolder.

External Website

<a href="https://vnu.edu.vn">VNU</a>

Full URL with https:// for external sites only.

Try It Now: Fix These Paths

Slide 9 of 30 #

Five minutes — fix four broken links

You are editing pages/about.html. Fix these hrefs:

html
1<!-- Bug 1: link to home page -->2<a href="index.html">Home</a>34<!-- Bug 2: link to contact page -->5<a href="contact.html">Contact</a>67<!-- Bug 3: link to stylesheet -->8<link rel="stylesheet" href="style.css">910<!-- Bug 4: link to image -->11<img src="images/logo.png" alt="Logo">

What to check

about.html is inside pages/. To reach index.html, you need to go UP one folder.

contact.html is in the same folder — no ../ needed.

style.css is in css/, which is at the root — need ../css/style.css.

images/ is at the root — need ../images/logo.png.

i
Open each fixed link in the browser. If you see a 404, the path is still wrong.

Step 1 — File > Save As > about.html (same folder).

Common Mistakes

Slide 16 of 30 #

Common Mistakes (and How to Fix Them)

×
Forgetting to move the active class — wrong page appears highlighted. FIX: Always move it when creating a new page.
×
Broken relative links — wrong filename casing or absolute file paths. FIX: Use lowercase, forward slashes, relative paths only.
×
Inconsistent page structure — missing <aside> on one page breaks the layout. FIX: Keep header/nav/aside/footer identical on every page.
×
Different CSS paths — every page must link to css/style.css identically. FIX: Copy the <link> tag from index.html.
×
Duplicate <title> tags — each page needs a unique, descriptive title. FIX: Format "Student Club - Page Name".
×
Forgetting to test all links. FIX: Click through every nav link from every page before submitting.

Debug This

Slide 17 of 30 #

Three broken links. Find them.

This nav looks correct and has three bugs

html
1<!-- in pages/about.html -->2<nav>3  <ul>4    <li><a href="index.html">Home</a></li>5    <li><a href="about.html" class="active">About</a></li>6    <li><a href="Pages/contact.html">Contact</a></li>7  </ul>8</nav>9<link rel="stylesheet" href="style.css">

Bugs

1. href="index.html" — wrong. about.html is in pages/, so Home needs ../index.html.

2. href="Pages/contact.html" — wrong casing. Folder is pages/ (lowercase), not Pages/.

3. href="style.css" — wrong path. CSS is in ../css/style.css, not in the pages/ folder.

i
Rule: every path is relative to WHERE the file is, not where the root is.

Worked Example: Gallery Grid

Slide 19 of 30 #

Building a Photo Gallery with Flexbox

css
1.gallery {2  display: flex;3  flex-wrap: wrap;4  gap: 15px;5}6.gallery-item {7  flex: 1 1 200px;   /* grow, shrink, basis */8  border-radius: 8px;9  overflow: hidden;10  box-shadow: 0 2px 8px rgba(0,0,0,0.08);11}12.gallery-item img {13  width: 100%;14  height: auto;15  display: block;     /* removes bottom gap */16}

Key properties:

flex-wrap: wrap — items flow to next line when space runs out.

flex: 1 1 200px — start at 200px, grow/shrink as needed.

overflow: hidden — clips images that exceed container.

display: block on img — removes the mysterious 4px gap below inline images.

Result: Responsive photo grid that adjusts columns automatically when you resize the browser.

Styling Contact Forms

Slide 21 of 30 #

Contact Page: Form Best Practices

html
1<form action="#" method="post">2  <label for="name">Your Name</label>3  <input type="text" id="name" required>45  <label for="email">Email</label>6  <input type="email" id="email" required>78  <label for="message">Message</label>9  <textarea id="message" rows="5"></textarea>1011  <button type="submit">Send</button>12</form>

Form styling tips:

label above input — display: block on labels for stacked layout.

:focus state — outline or border-color change shows active field.

required attribute — browser validates before submission.

for/id pairing — clicking label focuses the input (accessibility).

button styling — background, padding, cursor: pointer.

!
Always pair <label for="x"> with <input id="x">. Screen readers depend on this connection.

Try It Now: Style a Contact Form

Slide 22 of 30 #

Five minutes — make a form look professional

Add this CSS to style your form

css
1form {2  max-width: 500px;3  margin: 0 auto;4}56label {7  display: block;8  margin-bottom: 4px;9  font-weight: bold;10}1112input, textarea {13  width: 100%;14  padding: 10px;15  margin-bottom: 16px;16  border: 1px solid #ccc;17  border-radius: 4px;18  box-sizing: border-box;19}

What to check

1. Labels appear above their inputs (not beside them).

2. Inputs stretch to the full width of the form.

3. There is space between each field (margin-bottom).

4. The form is centered on the page (max-width + margin: auto).

i
box-sizing: border-box is critical — without it, padding makes inputs wider than 100%.

Accessibility Checklist

Slide 23 of 30 #

Every Page Must Pass These Checks

Images

Every <img> has a descriptive alt attribute — not just alt="image".

Links

Link text is meaningful — not "click here" but "Read about our events."

Headings

Headings are in order: h1 → h2 → h3. No skipping levels.

Navigation

Nav is identical on every page — same links, same order.

Language

<html lang="en"> is set on every page.

Contrast

Text is readable against the background — no light gray on white.

!
Accessibility is not optional. A site that is hard to read or navigate loses marks even if it looks pretty.

Multi-Page Sites: Do vs Don't

Slide 25 of 30 #

Do vs Don't

Do

Use relative links (about.html, ../index.html)

Put class="active" on the current page's nav link

Share one CSS file across all pages

Test every link from every page

Use consistent folder structure (pages/, css/, images/)

Don't

Use absolute paths (C:\Users\...\index.html)

Copy-paste CSS into each page's <style> tag

Forget to update nav on newly added pages

Mix uppercase and lowercase in file names

Leave broken links — they look worse than no nav
