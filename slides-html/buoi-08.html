Debug This: Exam-Style

Slide 17 of 31 #

This exam answer has four errors. Find them.

Student's answer

html
1<!DOCTYPE html>2<html lang="en">3<head>4  <meta charset="UTF-8">5  <title>My Club</title>6</head>7<body>8  <header>9    <h1>Welcome<h1>10    <nav>11      <a href="index.html">Home</a>12      <a href="about.html">About</a>13    </nav>14  </header>15  <main>16    <p class="intro">We meet every Friday.17  </main>18</body>19</html>

Errors

1. <h1>Welcome<h1> — missing / in closing tag. Should be </h1>.

2. No <link rel="stylesheet"> — the CSS file is not connected.

3. <p class="intro"> — missing closing </p> tag.

4. No <meta name="viewport"> — page will not be responsive.

i
In the exam, check every opening tag has a closing tag. Count them: <h1>...</h1>, <p>...</p>, <a>...</a>.

More Exam Pitfalls

Additional Common Mistakes

Forgetting alt attribute on <img> → -0.15 points per rubric.
×
Using absolute paths (C:\Users\...) instead of relative → -0.25 points.
×
Not creating activities.html at all → -0.5 points immediately.

Exam day tips

Slide 20 of 31 #

Maximise your marks

Read ALL 4 problems first — budget your time, tackle easier ones first.

Write EVERY file — partial code earns partial marks (2+3+3+2 = 10).

Save frequently — use Ctrl+S after every change. Don't lose work.

Check file names and paths: about.html, css/style.css, images/logo.png.

Use comments: <!-- navigation --> and /* nav styles */ show understanding.

If stuck on one problem, move on — come back later. Secure easy marks first.

Write the CSS (from memory)

css
1.container {2  display: flex;3  gap: 20px;4}56aside { flex: 1; }7main { flex: 2; }

Checklist

☐ display: flex on the PARENT (container)

☐ flex: 1 and flex: 2 on the CHILDREN

☐ gap for spacing between columns

☐ justify-content if you need alignment

i

Exam Strategy: Read, Plan, Code, Check

Slide 23 of 31 #

Four Steps for Every Exam Question

Step 1: Read (2 min)

Read the question twice. Underline what they are asking for.

Step 2: Plan (1 min)

Sketch the HTML structure in your head. Which tags? Which selectors?

Step 3: Code (5 min)

Write HTML first, then CSS. Do not try to do both at once.

Step 4: Check (2 min)

Count closing tags. Check semicolons. Verify selectors match.

Time management

90 minutes ÷ 10 questions = 9 minutes per question.

If stuck, skip and come back. Do not spend 20 minutes on one question.

Easy questions first — build confidence and secure marks.

!
The #1 cause of lost marks is not lack of knowledge — it is rushing and making careless errors.

Exam: Do vs Don't

Slide 24 of 31 #

Exam Do vs Don't

Do

Read every question twice before writing

Write HTML structure first, then CSS

Check for closing tags and semicolons

Use meaningful class names (not .x or .thing)

Leave time to review all answers

Don't

Rush through without reading carefully

Skip the boilerplate (DOCTYPE, html, head, body)

Forget the viewport meta tag

Use inline styles (style="...") instead of CSS file

Leave any question blank — write something

Accessibility Marks You Can Bank

Slide 30 of 31 #

Cheap Points the Marker Always Checks

lang

<html lang="en"> on every page. One attribute, always marked.

alt

Descriptive alt on every <img>. Decorative images get alt="" — empty, but present.

Headings

One <h1>, then h2 and h3 in order. Never skip a level to get a smaller font.

Labels

Every form input has a <label for="id">. Placeholder text is not a label.

Landmarks

header, nav, main, footer instead of four anonymous divs.

Contrast

Body text at 4.5:1 or better. Avoid light grey on white.

i
In a 90-minute exam these six checks take about three minutes and are the most reliable marks on the paper.
