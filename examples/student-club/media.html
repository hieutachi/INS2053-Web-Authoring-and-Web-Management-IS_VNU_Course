Tutorial Transcript

Welcome to this original CodeBreakers teaching tutorial. CodeBreakers is a fictional student club. This recording explains how to make your first HTML page. Start with a folder for your website. Create a file named index.html. Add the HTML5 doctype, the HTML element with English language, a head, and a body. In the head, declare UTF-8, set the viewport, and write a descriptive title. In the body, add one main heading with your club name and two paragraphs describing your club.

Save the file and open it in your browser. The title appears on the tab. The heading and paragraphs appear on the page. Next, create separate About, Activities, Media, and Contact files. Keep all five pages at the same folder level. Link them with relative file names. Put your shared stylesheet in the CSS folder and your own images in the images folder.

Finally, test every link, use the keyboard, and check the website with the network switched off. Build a small working page first, then improve it one milestone at a time.
