## 8. Recommended Reading Order

For students following the INS2053 course, read resources in this order:

1. **Week 1–3:** MDN HTML Basics → MDN Introduction to HTML
2. **Week 4:** MDN CSS First Steps → MDN CSS Selectors
3. **Week 5–6:** MDN Box Model → CSS-Tricks Box Sizing
4. **Week 7:** MDN CSS Fonts and Text → MDN CSS Layout
5. **Week 8:** Review → Practice with Validators
6. **Week 9:** MDN HTML Tables → MDN Tables tutorial
7. **Week 10:** MDN Video and Audio Content
8. **Week 11–12:** Practice exercises → Build milestone pages
9. **Week 13:** MDN HTML Forms → MDN Forms learning path
10. **Week 14–15:** MDN Responsive Design → MDN Media Queries → Validate with W3C tools
