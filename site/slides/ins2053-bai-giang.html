How the web works

How the web works

Your browser asks a server for a page; the server sends back files; the browser draws them. Every single thing in this course happens inside that loop.

HTML gives structure

Headings, paragraphs, lists, images — the skeleton of every page.

<h1> … <h6><p> paragraph<ul> / <ol> lists<img> with alt

Sessions 1–3

CSS = style

Slide 4 of 12 #

CSS gives style — the box model

Every element is a box: margin, then border, then padding, then the content. Use box-sizing: border-box so width means what you think it means.

Tables for tabular data

Slide 7 of 12 #

Tables — for data, not layout

Use table / thead / tbody / caption; merge cells with colspan & rowspan.

Remember: a rowspan cell means fewer cells in the next row. Session 9.
