What Is CSS?

Slide 5 of 34 #

What Is CSS?

CSS = Cascading Style Sheets. It tells the browser how HTML should look.

i
Analogy: HTML = bricks and walls of a house. CSS = paint, wallpaper, and furniture.

Separation of concerns — HTML handles meaning; CSS handles looks.

Consistency — one stylesheet styles every page.

Efficiency — change one file instead of dozens.

Three Ways to Add CSS

Slide 7 of 34 #

Three Ways to Add CSS

Inline

style="..." on the element. One element only. Avoid in production.

Internal

<style> in <head>. One page only. Rarely used.

External

Separate .css file linked via <link>. One file for the entire site.

<link rel="stylesheet" href="css/style.css">

CSS Selectors

Slide 11 of 34 #

Selectors: Element, Class, ID

Elementp { color: #333; }

Targets ALL elements of that tag. Low specificity (0,0,1).

Class
css
1.highlight {2  background: #ffffcc;3}

Reusable on many elements. Medium specificity (0,1,0).

ID
css
1#header {2  background: #1a5276;3}

Unique per page. High specificity (1,0,0). Use sparingly.

12

Selector Reference Table

Slide 12 of 34 #

When to use which selector

SelectorExampleMatches
ElementpEvery <p> on the page

ID#headerThe one element with id="header"
Descendantnav aEvery <a> inside a <nav>
Pseudo-classa:hoverAny <a> the mouse is over
!
Prefer classes over IDs. Classes are reusable and easier to override.

Descendant selectors and pseudo-classes let you target elements precisely without adding extra classes everywhere.

Margin vs Padding

Slide 18 of 34 #

The difference that trips everyone up

Padding = INSIDE

Space between content and border.

Gets the background color.

css
1padding: 15px;2padding: 10px 20px;
Margin = OUTSIDE

Space between this element and others.

Never gets a background color.

css
1margin: 20px;2margin: 10px auto;
i
Remember: padding is like stuffing inside a box. Margin is the space between boxes on a shelf.
19

Start with a CSS Reset

Slide 19 of 34 #

Why start every stylesheet with a reset?

css
1/* Put this at the TOP of style.css */2* {3    margin: 0;4    padding: 0;5    box-sizing: border-box;6}

margin: 0; padding: 0 — removes browser-default spacing so YOU control everything.

box-sizing: border-box — width includes padding and border. No more surprise sizes.

* — the universal selector. Applies to EVERY element on the page.

!
Without a reset, different browsers apply different default margins. Your layout will be inconsistent.

Worked Example 1: Body & Typography

Slide 21 of 34 #

Setting base styles for the whole site

css
1/* === BASE STYLES === */2* {3    margin: 0;4    padding: 0;5    box-sizing: border-box;6}78body {9    font-family: Arial, sans-serif;10    font-size: 16px;11    line-height: 1.6;12    color: #333333;13    background-color: #f5f5f5;14}1516h1 { color: #2c3e50; font-size: 28px; }17h2 { color: #2980b9; font-size: 22px; }18p  { margin-bottom: 12px; }

* — resets ALL elements. Always put this first.

body — sets defaults inherited by child elements.

line-height: 1.6 — comfortable reading spacing.

h1, h2 — distinct colors create visual hierarchy.

margin-bottom — adds space below paragraphs.

i
In the browser: light gray background, dark readable text, blue headings, spaced paragraphs.

Worked Example 2: Styling the Header

Slide 22 of 34 #

Full header stylesheet explained

css
1/* === HEADER === */2header {3  background-color: #1a5276;4  color: white;5  text-align: center;6  padding: 30px 20px;7}89header h1 {10  font-size: 36px;11  margin-bottom: 10px;12}1314header p {15  font-size: 18px;16  opacity: 0.9;17}

background-color — dark blue fills the entire header area.

color: white — all text inside header turns white. Child elements inherit this.

padding: 30px 20px — 30px top/bottom, 20px left/right. Creates breathing room.

header h1 — descendant selector: targets only <h1> INSIDE <header>, not elsewhere.

opacity: 0.9 — subtitle is slightly transparent, creating visual hierarchy.

i
In the browser: a full-width dark blue bar with large white centred title and a softer subtitle beneath it.

Save css/style.css → Ctrl+S → refresh browser to see changes.

Discussion: Why Separate CSS from HTML?

Slide 23 of 34 #

Why not just style everything inline?

Imagine 10 pages, each with inline styles. Want to change the heading color?

You would have to edit ALL 10 files. With external CSS, you edit ONE file.

Separation also means designers and developers can work independently.

i
One stylesheet → one place to update → instant site-wide changes.

Debug This

Slide 24 of 34 #

This CSS has three bugs. Find them.

Buggy CSS

css
1body {2  font-family: Arial, sans-serif;3  background-color: #f5f5f5;4  color: #333;5  margin: 0;6  padding: 20px;7}89h1 {10  color: #2c3e50;11  border-bottom: 2px solid #3498db;12  padding-bottom: 10px;13}1415.intro {16  font-size: 18px;17  line-height: 1.6;18  color: #666;19}

Bugs

1. No <link rel="stylesheet" href="style.css"> in the HTML — the CSS file is not connected to the page.

2. .intro class is defined but no HTML element has class="intro" — the style will never apply.

3. No box-sizing: border-box — padding will add to the total width, causing layout issues.

i
Rule: CSS only works if (1) the file is linked, (2) selectors match HTML elements, and (3) the box model is predictable.

Common Mistakes

Slide 25 of 34 #

Common Mistakes

×
Forgetting to link the CSS file — no <link> in <head> means no styles.
×
Wrong selector syntax — using # for a class or . for an ID.
×
Missing semicolons — color: navy (no ;) breaks the next declaration.
×
Confusing margin vs padding — margin = outside, padding = inside.
×
No CSS reset — browsers apply different default margins. Start with * { margin: 0; padding: 0; box-sizing: border-box; }
×
Wrong path in <link> — from pages/ subfolder, use ../css/style.css not css/style.css
×
Using !important — it wins now but blocks fixes later. Use better selectors instead.

CSS: Do vs Don't

Slide 29 of 34 #

Do vs Don't

Do

Keep all CSS in one external css/style.css

Style with classes: .card, .btn, .nav-link

Start the file with a reset: margin, padding, box-sizing

Group related rules and comment each section

Use rem or em for font sizes so text scales with user settings

Don't

Sprinkle style="..." attributes through the HTML

Chain long selectors like body div div p span

Reach for !important to win a specificity fight

Style by id (#header) when a class would be reusable

Hard-code the same colour value in twelve places

Accessible Colour and Type

Slide 30 of 34 #

Styling Decisions That Decide Readability

Contrast

Body text needs a contrast ratio of at least 4.5:1 against its background. #999 on white fails; #595959 passes.

Font size

Never set body text below 16px. Small type is the most common complaint on student sites.

Line height

line-height: 1.5 or more for paragraphs. Tight lines are hard to track for dyslexic readers.

Colour alone

Never use colour as the only signal. Add an icon, underline, or label so colour-blind users get the message too.

Focus

Never write outline: none without providing a replacement focus style. Keyboard users need to see where they are.

i
Check contrast in DevTools: inspect the element, click the colour swatch, and read the contrast ratio it reports.

Assignment: Style Your Site

Slide 32 of 34 #

Start in class — finish for homework

Deliverable

css/style.css linked from every page of your Student Club Website, with zero inline style attributes remaining.

Acceptance criteria

A reset block at the top of the file.

Body typography set: font-family, font-size, line-height, colour.

Header and nav styled with class selectors.

At least one reusable class used on two or more elements.

Before you submit

Validate the CSS at jigsaw.w3.org/css-validator.

Search your HTML for style=" — there should be no hits.

Check text contrast on every coloured background.

!
One stylesheet for the whole site. The moment you copy CSS into a second file, the two versions start drifting apart.
