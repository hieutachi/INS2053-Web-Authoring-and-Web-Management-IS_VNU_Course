One rule to remember

Do not hunt through folders

Start from a session page. It is the single front door for that week; from there, move through the chapter, slide deck and homework in order. Use the top navigation only when you need a whole collection.

Practice mode. Online submission is not enabled yet. Hand in through your own Git repository: push the code tasks, then add your Google Drive link to homework/submissions.md — the reference rubric below grades the code (10 pts); the video is graded separately (4 pts).
